# Combine — обзор проекта (русское издание)

Эта книга представляет собой русскоязычное издание пользовательской
документации библиотеки Combine — чисто Swift-реализации одноимённого
фреймворка Apple, предназначенной в первую очередь для платформы Linux.
Библиотека реализует официальный набор типов и операторов (321 тип,
1091 проверяемое объявление), каждое поведение которой подтверждается
автоматизированными тестами.

Русское издание ориентировано на читателя, ранее не работавшего с
фреймворками Apple: основные понятия объясняются с нуля, термины API
(`publisher`, `subscriber`, `demand`, `sink`) сохраняются в
английском написании и получают определения по-русски при первом
употреблении. Тексты глав сопровождаются примерами кода; каждый пример
компилируется и выполняется в тестовом наборе
`Tests/DocumentationExamplesTests`, что исключает расхождение
документации и фактического поведения.

## Состав издания

1. [INTRO.md](INTRO.md) — введение в реактивный подход: издатель,
   подписчик, подписка, спрос (backpressure), завершение потоков и
   обращение с ошибками.
2. [GETTING-STARTED.md](GETTING-STARTED.md) — установка и первые
   конвейеры.
3. [CONCEPTS.md](CONCEPTS.md) — арифметика спроса, отмена, стирание
   типов, модель потоков.
4. [OPERATORS.md](OPERATORS.md) — каталог операторов по категориям.
5. [SCHEDULERS.md](SCHEDULERS.md) — планировщики и переходы между
   потоками выполнения.
6. [SUBJECTS-AND-STATE.md](SUBJECTS-AND-STATE.md) — субъекты,
   `@Published`, `ObservableObject`.
7. [FOUNDATION.md](FOUNDATION.md) — мосты к Foundation и границы
   реализации (KVO не реализован осознанно).
8. [ASYNC-AWAIT.md](ASYNC-AWAIT.md) — взаимодействие с асинхронными
   последовательностями.
9. [COMPATIBILITY.md](COMPATIBILITY.md) — матрица совместимости,
   методика подтверждения паритета, вопросы и ответы.

## Статус библиотеки

- Реализовано 321 из 321 официальных символов (100 %); 1091 объявление
  проверяется автоматически (`docs/DECL-AUDIT.md`).
- Поведение подтверждается заимствованным набором тестов
  OpenCombine-паритета (свыше тысячи тестов) и собственными тестами
  там, где эталона поведения не существует.
- Единственное осознанное исключение — привязка к KVO (отсутствует на
  Linux); подробности в [COMPATIBILITY.md](COMPATIBILITY.md).

Инженерская документация (регистр особенностей поведения, отчёт о
производительности, инвентарь API) ведётся на английском языке в
каталоге `docs/` корневого репозитория и в этот том не входит.

## Сборка тома в PDF

Русский том рендерится тем же инструментом, что и английский:

```bash
python3 Tools/render_docs_pdf.py --lang ru
```

Результат — `docs/ru/LinuxCombine-Documentation-RU.pdf`. Требуемые
Python-пакеты перечислены в `Tools/requirements-pdf.txt`.
